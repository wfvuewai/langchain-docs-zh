使用声明式权限规则控制智能体可以读取或写入的文件和目录。将规则列表传递给 `permissions=`，智能体的内置文件系统工具将遵守这些规则。

:::python
<Note>
    权限功能需要 `deepagents>=0.5.2`。
</Note>
:::

:::js
<Note>
    权限功能需要 `deepagents>=1.9.1`。
</Note>
:::

权限仅适用于内置文件系统工具（`ls`、`read_file`、`glob`、`grep`、`write_file`、`edit_file`）。访问文件系统的自定义工具和 MCP 工具不受覆盖。权限也不适用于[沙箱后端](/zh/oss/deepagents/sandboxes)，后者通过 `execute` 工具支持任意命令执行。

<Tip>
当你需要在内置文件系统工具上实施**基于路径的允许/拒绝规则**时，使用 `permissions`。当你需要自定义验证逻辑（速率限制、审计日志、内容检查）或需要控制自定义工具时，使用[后端策略钩子](/zh/oss/deepagents/backends#add-policy-hooks)。
</Tip>

## 基本用法

:::python

向 @[`create_deep_agent`] 传递 @[`FilesystemPermission`] 规则列表。规则按声明顺序求值。第一条匹配的规则胜出。如果没有规则匹配，则允许该操作。

## 规则结构

:::python

每个 `FilesystemPermission` 有三个字段：

| 字段 | 类型 | 说明 |
|-------|------|------|
| `operations` | `list["read" \| "write"]` | 此规则适用的操作。`"read"` 涵盖 `ls`、`read_file`、`glob`、`grep`。`"write"` 涵盖 `write_file`、`edit_file`。 |
| `paths` | `list[str]` | 用于匹配文件路径的 Glob 模式（例如 `["/workspace/**"]`）。支持 `**` 递归匹配和 `{a,b}` 交替匹配。 |
| `mode` | `"allow" \| "deny"` | 是允许还是拒绝匹配的操作。默认为 `"allow"`。 |

规则使用首匹配胜出求值：第一条 `operations` 和 `paths` 与当前调用匹配的规则决定结果。如果没有规则匹配，则调用被**允许**（宽松默认）。

:::

:::js

每个 `FilesystemPermission` 有三个字段：

| 字段 | 类型 | 说明 |
|-------|------|------|
| `operations` | `("read" \| "write")[]` | 此规则适用的操作。`"read"` 涵盖 `ls`、`read_file`、`glob`、`grep`。`"write"` 涵盖 `write_file`、`edit_file`。 |
| `paths` | `string[]` | 用于匹配文件路径的 Glob 模式（例如 `["/workspace/**"]`）。支持 `**` 递归匹配和 `{a,b}` 交替匹配。 |
| `mode` | `"allow" \| "deny"` | 是允许还是拒绝匹配的操作。默认为 `"allow"`。 |

规则使用首匹配胜出求值：第一条 `operations` 和 `paths` 与当前调用匹配的规则决定结果。如果没有规则匹配，则调用被**允许**（宽松默认）。

路径必须是绝对路径（以 `/` 开头），不能包含 `..` 或 `~`。无效路径会在智能体构建时抛出异常。

:::

## 子代理权限

:::python

[子代理](/zh/oss/deepagents/subagents)默认继承父智能体的权限。要为子代理设置不同的权限，请在其配置中设置 `permissions` 字段。这会**完全替换**父级的规则。

<PermissionsSubagentPy />

:::

:::js

[子代理](/zh/oss/deepagents/subagents)默认继承父智能体的权限。要为子代理设置不同的权限，请在其配置中设置 `permissions` 字段。这会**完全替换**父级的规则。

<PermissionsSubagentJs />

要显式授予子代理无限制访问权限，请设置 `permissions: []`。空数组会用无限制规则覆盖父级规则。省略 `permissions` 则继承自父级。

:::

## 复合后端

:::python

当使用带有沙箱默认值的 @[`CompositeBackend`] 时，每个权限路径必须限定在已知路由前缀下。沙箱支持任意命令执行，因此仅靠基于路径的限制无法阻止通过 Shell 命令访问文件系统。将权限限定到特定路由的[后端](/zh/oss/deepagents/backends)可以避免此冲突。
