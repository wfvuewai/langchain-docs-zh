## 智能体框架（如 LangChain）

智能体框架提供抽象层，使基于 LLM 的应用更容易起步。

[LangChain](/oss/langchain/overview) 是一个智能体框架，提供结构化内容块、智能体循环和中间件等抽象。

LangChain 的抽象设计目标是“上手快”，同时保留高级场景所需的灵活性。

虽然 LangChain 构建于 [LangGraph](/oss/langgraph/overview) 之上，但你不需要先学习 LangGraph 才能使用 LangChain。

其他常见智能体框架包括 [Vercel 的 AI SDK](https://ai-sdk.dev/docs/introduction)、[CrewAI](https://www.crewai.com/)、[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)、[Google ADK](https://google.github.io/adk-docs/) 和 [LlamaIndex](https://www.llamaindex.ai/) 等。

### 何时使用 LangChain

使用 LangChain 的场景包括：

- 希望快速构建智能体和自治应用。
- 需要对模型、工具和智能体循环使用标准抽象。
- 既要易用，又要在后续保持扩展性。
- 构建结构相对直接、无需复杂编排的智能体应用。

## 智能体运行时（如 LangGraph）

智能体运行时提供在生产环境中运行智能体所需的工具栈。
常见能力包括：

- **持久化执行**：智能体可跨错误继续执行，支持长时间运行并从中断点恢复。
- **流式处理**：支持工作流和响应流式化。
- **人机协同**：支持在执行中检查与修改智能体状态。
- **持久化**：线程级与跨线程持久化用于状态管理。
- **底层控制**：在较低层面直接控制编排逻辑。

[LangGraph](/oss/langgraph/overview) 是一个低层编排框架与运行时，用于构建、管理和部署运行时间较长、带状态的智能体。

一般来说，智能体框架是更高层的概念，运行在智能体运行时之上，例如 LangChain 1.0 也是构建在 LangGraph 之上。

其他常见运行时还包括 [Temporal](https://temporal.io/) 和 [Inngest](https://www.inngest.com/) 等耐久化执行引擎。

### 何时使用 LangGraph

在以下场景可优先考虑 LangGraph：

- 需要细粒度、低层级的编排控制。
- 需要长时间运行且带状态的智能体。
- 需要将确定性流程与智能体决策流程混合的复杂工作流。
- 需要生产级智能体部署基础设施。

## 智能体 Harness（如 Deep Agents SDK）

智能体 harness 是一种偏“开箱即用”的框架，提供内置工具与能力，适合构建复杂、长期运行的智能体。
常见能力包括：

- **规划能力**：使用待办列表跟踪多任务。
- **任务委派**：借助子智能体拆解任务并保持上下文整洁。
- **文件系统**：在可插拔存储后端上进行文件读写。
- **token 管理**：对对话历史进行摘要并清理大体积工具结果。

[Deep Agents SDK](/oss/deepagents/overview) 建立在 LangGraph 之上，新增规划能力、上下文管理文件系统、可生成子智能体等能力。
Deep Agents 适合需要规划和分解的复杂多步骤任务。

示例任务包括在状态中处理搜索结果、脚本和其他产物。

其他同类 harness 示例包括 [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview)、[Manus](https://manus.im/) 以及其他代码型 CLI。

### 何时使用 Deep Agents SDK

在以下场景下可以选择 [Deep Agents SDK](/oss/deepagents/overview)：

- 构建运行周期较长的智能体。
- 需要处理复杂、多步骤任务。
- 你想使用预置工具，例如文件系统操作、bash 执行、自动上下文工程。
- 你想依赖预置提示词与子智能体。
