---
title: 消息队列
description: 管理消息队列以实现高效处理和持久化
---

消息队列通过将消息处理与 agent 执行分离，为你提供了一种管理 agent 输入和输出的方法。消息队列对于构建响应迅速、可扩展的应用至关重要。

在典型设置中，队列负责：

1. **接收**用户请求。
2. **批处理**多个请求。
3. **将请求分派**给 agent 进行异步处理。
4. **收集** agent 输出。
5. **将完成的输出返回**给前端。

理想情况下，消息队列通过确保在等待 agent 执行时不阻塞前端来帮助维持良好的用户体验。它们还通过减少同时发送到 agent 的请求数量来帮助管理负载。

虽然 LangChain 没有内置的消息队列系统，但你可以使用你生态系统中熟悉的消息队列框架来在 agent 前后端和前端客户端之间路由消息。常见的选项包括 RabbitMQ、Apache Kafka 和 Redis Pub/Sub。

### 前端队列管理

从 UI 的角度来看，消息队列可以帮助你实现：

- **乐观 UI 更新**：在用户发送消息后立即显示，即使在队列中等待处理。
- **连接恢复**：如果客户端断开连接，在重新连接时重新播放或恢复消息。
- **批处理**：将多个用户操作分组为单个 agent 处理请求。
- **优先级**：高优先级消息可以跳过队列中的其他消息。
