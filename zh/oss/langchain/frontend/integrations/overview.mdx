---
title: 概述
description: 将 useStream 连接到任何 React UI 组件库或生成式 UI 框架
---

@[`useStream`] 是与 UI 无关的。它返回带有消息、工具调用、加载状态和线程历史的纯响应式状态，你可以将其连接到任意视觉层。这些页面展示了不同库如何与 LangChain 前端集成，每种库在构建 AI 聊天和生成式 UI 方面都有不同的理念。

## 集成

<CardGroup cols={2}>
  <Card title="CopilotKit" icon="package" href="/oss/langchain/frontend/integrations/copilotkit">
    完整的 AI 聊天运行时，支持结构化生成式 UI。向你的 LangGraph 部署添加自定义 CopilotKit 端点，然后在 React 中渲染动态组件树。
  </Card>
  <Card title="AI Elements" icon="package" href="/oss/langchain/frontend/integrations/ai-elements">
    基于 shadcn/ui 的可组合组件，用于 AI 聊天。直接使用 `Conversation`、`Message`、`Tool` 和 `Reasoning` 组件，并将其直接连接到 `stream.messages`。
  </Card>
  <Card title="assistant-ui" icon="package" href="/oss/langchain/frontend/integrations/assistant-ui">
    无头 React 框架，具有完整的运行时层。通过 `useExternalStoreRuntime` 适配器将 `useStream` 桥接到 `AssistantRuntimeProvider`。
  </Card>
  <Card title="OpenUI" icon="package" href="/oss/langchain/frontend/integrations/openui">
    生成式 UI 库，让代理能够以声明式组件 DSL 生成完整的、交互式仪表盘。专为数据密集型、报表式 UI 而构建。
  </Card>
</CardGroup>

## 选择库

每个库适用于略有不同的集成模型。选择取决于你正在构建的 UI 类型：

| | CopilotKit | AI Elements | assistant-ui | OpenUI |
| --- | --- | --- | --- | --- |
| **最适合** | 完整的聊天运行时加结构化生成式 UI | 具有丰富消息类型的聊天 | 功能完整的聊天，设置简单 | 生成的仪表盘和报表 |
| **UI 风格** | CopilotKit 聊天外壳 + 自定义消息渲染器 | 可组合的 shadcn/ui 组件 | 无头插槽 + 默认主题 | 预构建组件库，带声明式 DSL |
| **定制化** | 自定义后端端点、代理上下文和渲染器 | 直接编辑源文件 | 覆盖组件插槽 | 通过 CSS 自定义属性设置主题 |
| **流式 UX** | 运行时管理的聊天流，带有结构化助手负载 | 组件级别的渐进式渲染 | 内置线程管理 | 提升——外壳立即显示，数据逐渐填充 |
| **工具调用** | 通过 CopilotKit 运行时和自定义渲染器 | `Tool` / `ToolHeader` / `ToolOutput` | 通过消息插槽自定义 | 内联在生成的 UI 中 |
| **代理格式** | 结构化助手响应加可选的 Markdown | 任意 `stream.messages` | 任意 `stream.messages` | 代理输出 openui-lang 文本 |

所有四个库都能很好地与 LangChain 代理配合使用，后三个库也可以直接连接到 @[`useStream`]。当你需要更丰富的运行时层和一个可以与 [LangGraph](/oss/langgraph/overview) 部署并存的专用端点时，CopilotKit 尤其有用。
