---

智能体应用程序允许 LLM 自行决定下一步要做什么来解决问题。这种灵活性非常强大，但模型的黑盒特性使得难以预测智能体某个部分的变化会如何影响整体。要构建生产就绪的智能体，彻底的测试至关重要。

以下是几种测试智能体的方法：

- **单元测试** 使用内存中的模拟对象隔离地测试智能体中小的、确定性的部分，以便你可以快速、确定性地断言精确行为。
- **集成测试** 使用真实的网络调用测试智能体，以确认组件协同工作、凭据和模式匹配、以及延迟可接受。
- **评估（Evals）** 使用评估器评估智能体的执行轨迹，可以通过确定性匹配或 LLM 评判器。

智能体应用程序通常更依赖集成测试，因为它们将多个组件串联在一起，并且必须处理由于 LLM 的非确定性特性带来的不稳定性。

<Tip>
使用 [LangSmith](https://smith.langchain.com) 大规模运行评估、追踪随时间变化的结果并比较实验。参见[评估 LLM 应用程序](/langsmith/evaluate-llm-application)快速入门。
</Tip>
