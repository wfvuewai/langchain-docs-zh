本指南将带你创建第一个具备规划、文件系统工具和子代理能力的 Deep Agent。你将构建一个能够进行调研并撰写报告的研究智能体。

<Tip>
    **使用 AI 编码助手？**

    - 安装 [LangChain Docs MCP 服务器](/zh/use-these-docs) 让你的智能体能访问最新的 LangChain 文档和示例。
    - 安装 [LangChain Skills](https://github.com/langchain-ai/langchain-skills) 以提升智能体在 LangChain 生态系统任务上的表现。
</Tip>

## 前置条件

开始之前，请确保你拥有一个模型提供商的 API 密钥（例如 Gemini、Anthropic、OpenAI）。

<Note>
    Deep Agents 需要一个支持[工具调用](/zh/oss/langchain/models#tool-calling)的模型。请参阅[自定义](/zh/oss/deepagents/customization#model)了解如何配置你的模型。
</Note>

## 工作原理

你的 Deep Agent 会自动：

1. **规划方法**——使用内置的 [`write_todos`](/zh/oss/deepagents/harness#planning-capabilities) 工具分解研究任务
1. **进行调研**——调用 `internet_search` 工具收集信息
1. **管理上下文**——使用文件系统工具（[`write_file`](/zh/oss/deepagents/harness#virtual-filesystem-access)、[`read_file`](/zh/oss/deepagents/harness#virtual-filesystem-access)）卸载大量搜索结果
1. **生成子代理**——根据需要将复杂的子任务委派给专门的子代理
1. **综合报告**——将发现结果整理为连贯的回复

## 流式传输

Deep Agents 内置了[流式传输](/zh/oss/langchain/event-streaming)功能，通过 LangGraph 实现智能体执行的实时更新。这允许你逐步观察输出，并审查和调试智能体及子代理的工作，例如工具调用、工具结果和 LLM 响应。

## 下一步

现在你已经构建了第一个 Deep Agent：

- **自定义你的智能体**：了解[自定义选项](/zh/oss/deepagents/customization)，包括自定义系统提示词、工具和子代理。
- **添加长期记忆**：启用跨对话的[持久化记忆](/zh/oss/deepagents/memory)。
- **部署到生产环境**：使用[托管 Deep Agents](/zh/langsmith/deploy-managed-deep-agent) 在 LangSmith 中创建、运行和运维 Deep Agents。
