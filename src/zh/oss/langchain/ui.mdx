### 连接到你的智能体

智能体聊天 UI 可以连接到[本地](/oss/langchain/studio)和[已部署的智能体](/oss/langchain/deploy)。

启动智能体聊天 UI 后，你需要配置它以连接到你的智能体：

1. **Graph ID**：输入你的图名称（在 `langgraph.json` 文件的 `graphs` 下找到）
2. **Deployment URL**：你的智能体服务器端点（例如，本地开发使用 `http://localhost:2024`，或你的已部署智能体的 URL）
3. **LangSmith API key（可选）**：添加你的 LangSmith API 密钥（如果你使用本地智能体服务器，则不需要）

配置完成后，智能体聊天 UI 将自动获取并显示来自智能体的任何中断线程。

<Tip>
  智能体聊天 UI 内置支持渲染工具调用和工具结果消息。要自定义显示哪些消息，请参见[在聊天中隐藏消息](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat)。
</Tip>
