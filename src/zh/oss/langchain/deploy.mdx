当您准备将 LangChain 智能体部署到生产环境时，LangSmith 提供了一个专为智能体工作负载设计的托管平台。传统的托管平台是为无状态、短生命周期的 Web 应用程序构建的，而 LangGraph **专为需要持久状态和后台执行的有状态、长时间运行的智能体而设计**。LangSmith 负责处理基础设施、扩展和运维问题，使您可以直接从仓库进行部署。

## 前提条件

在开始之前，请确保您具备以下条件：

- 一个 [GitHub 账号](https://github.com/)
- 一个 [LangSmith 账号](https://smith.langchain.com)（免费注册）

## 部署您的智能体

### 1. 在 GitHub 上创建仓库

您的应用程序代码必须存在于 GitHub 仓库中，才能部署到 LangSmith。公共和私有仓库均受支持。对于本快速入门，首先请确保您的应用程序与 LangGraph 兼容。然后，将您的代码推送到仓库。
